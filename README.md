# SQL Data Analytics Project 📊

## 📌 Project Overview

This project is a practical SQL Data Analytics project focused on analyzing sales, customer, and product data using **MySQL**.

The project transforms raw transactional data into meaningful business insights by using SQL queries to analyze customer behavior, product performance, sales trends, and key business metrics.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze overall sales performance
- Understand customer purchasing behavior
- Analyze product performance
- Identify high-performing and low-performing products
- Segment customers based on spending and activity
- Analyze monthly sales trends
- Calculate important business KPIs
- Practice advanced SQL techniques for data analysis
